פרק 5
IDS / IPS

זיהוי ומניעת פלישה · חתימות · HIPS/NIPS · אזעקות
אבטחת מידע · מגמת תקשוב
חומת אש בודקת כתובות ופורטים. אבל התקפה יכולה להגיע בפורט שפתחנו. היום – מי שמסתכל לתוך התוכן.

למה חומת אש לא מספיקה

  • חומת אש: "TCP 80 ל-web – מותר" ✓
  • אבל בתוך אותה בקשה: SQL injection, ניצול חולשה
  • IDS/IPS מסתכלים על התוכן וההתנהגות
SQL Slammer (2003)חבילת UDP אחת הדביקה 75,000 שרתים ב-10 דקות. IPS עם חתימה אחת עצר את זה
Slammer ממחיש: מי שהיה עם IPS מעודכן – חתימה אחת חסמה. מי שרק חומת אש – נדבק.

שאלה

למה שמישהו יבחר IDS אם IPS גם מזהה וגם חוסם?

1. סיכון false positive – בבית חולים/בורסה חסימה בטעות גרועה מהחמצה. 2. ביצועים (inline יקר). 3. IDS פנימי רואה תנועה רוחבית שלא עוברת בחומת אש.
בפועל מפעילים את שניהם. מתחילים ב-IDS, מכווננים, עוברים ל-IPS.

HIPS רואה תעבורה מוצפנת אחרי הפענוח – יתרון מרכזי שנשאל.

שיטות זיהוי

  • חתימות – תבניות ידועות. מדויק, אך לא מזהה חדש (zero-day)
  • אנומליה – לומד "נורמלי", מתריע על חריגה. מזהה חדש, הרבה שגיאות
  • מדיניות – כללים שהמנהל מגדיר
  • Honeypot – פיתיון; כל גישה חשודה
חתימות = הנפוץ. אנומליה = ה-baseline. הדגישו את ה-trade-off דיוק מול כיסוי.

הגדרת IOS IPS

R1# mkdir ipsdir
R1(config)# ip ips config location flash:ipsdir
R1(config)# ip ips name MYIPS
R1(config)# ip ips signature-category
  category all → retired true       ! כבה הכול
  category ios_ips basic → retired false  ! הפעל בסיסי
R1(config-if)# ip ips MYIPS in
קטגוריה all retired ואז ios_ips basic unretired – זה הדפוס. בלי unretire אין חתימות פעילות.

דוגמה: התראה + חסימה על ping

R1(config)# ip ips signature-definition
R1(config-sigdef)# signature 2004 0   ! ICMP echo
  status → retired false, enabled true
  engine → event-action produce-alert
           event-action deny-packet-inline
זה התרגיל שעובד ב-Packet Tracerping נכשל + התראה בשרת syslog
produce-alert = התנהגות IDS. מוסיפים deny-packet-inline = IPS. הדגמה מצוינת להבדל.

שאלה

איזו פעולה לא זמינה ל-IDS שמחוץ לנתיב? 1. produce-alert 2. deny-packet-inline 3. reset-tcp-connection

2 – אי אפשר להפיל חבילה שכבר עברה; ה-IDS רואה רק עותק. הוא כן יכול לשלוח TCP reset.
מקשר את המיקום (מחוץ לנתיב) לפעולות האפשריות. reset הוא היחיד שגם IDS יכול.
