שאלת בגרות

איזו כתובת IPv6 מספקת תקשורת בין תתי-רשתות אך אינה ניתובה באינטרנט?

  • 1. global unicast
  • 2. link local
  • 3. multicast
  • 4. unique local
4 – unique local (המקבילה לכתובת פרטית ב-IPv4).
תנו לכיתה לנסות. link-local נפסל כי הוא רק על אותו קו, לא בין תתי-רשתות.

ניתוב סטטי ו-DHCP Relay

R1(config)# ip route 10.10.2.20 255.255.255.252 10.10.255.1
R1(config)# ip route 0.0.0.0 0.0.0.0 200.1.1.1   ! default
DHCP Relayבקשת DHCP היא broadcast ולא עוברת נתב. על ממשק הלקוח:
ip helper-address <IP של שרת ה-DHCP>
ip route: יעד + mask + next-hop. DHCP relay נשאל עם טופולוגיה – ההיגיון: helper-address על הממשק שפונה ללקוח.

VLAN ו-Router-on-a-Stick

R1(config)# interface g0/0/1.10
R1(config-subif)# encapsulation dot1Q 10
R1(config-subif)# ip address 172.18.1.254 255.255.0.0
  • VLAN = רשתות לוגיות מבודדות; מעבר ביניהן דורש ניתוב
  • Trunk 802.1Q נושא כמה VLANים בין מתגים
  • show mac address-table – טבלת ה-MAC של המתג
תת-ממשק לכל VLAN. שאלת השלמה נפוצה: interface .10 / encapsulation dot1Q / ip address.

STP מול OSPF – כללי הבחירה

STP – Root BridgePriority נמוך מנצח · בתיקו MAC נמוך · שכבה 2 · חסימת יציאות
OSPF – DR/BDRPriority גבוה מנצח · בתיקו Router-ID גבוה
שימו לב – הפוך!STP: נמוך מנצח · OSPF: גבוה מנצח
הבלבול הכי נפוץ. תרגלו: 4 מתגים priority זהה → MAC נמוך; OSPF priority זהה → RID גבוה.

סיכום – מה לזכור לבגרות

  • TCP=שכבה 4, UDP לא אמין · Unique Local = "פרטית" ב-IPv6
  • שמישים = 2n−2 · wildcard = 255... − mask
  • AD: Static 1, OSPF 110, RIP 120 (נמוך מנצח)
  • STP: MAC נמוך = root · OSPF: RID גבוה = DR
  • ip helper-address ל-DHCP · encapsulation dot1Q ל-VLAN
חמש הנקודות הכי נשאלות. חזרו עליהן לפני הבגרות.
