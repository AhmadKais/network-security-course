הקשחת נתב · SSH · syslog · NTP · SNMP · AutoSecure
אבטחת מידע · מגמת תקשוב
מהתיאוריה למעשה. היום נלמד להקשיח נתב סיסקו ב-CLI. פתחו Packet Tracer במקביל אם אפשר.

למה הנתב הוא מטרה ראשונה

  • נתב הקצה = הגבול בין הרשת לאינטרנט
  • מי ששולט בו – מנתב, מאזין, חוסם, פותח פתח
  • 3 תחומי הגנה: פיזי · מערכת הפעלה · הקשחה
Mirai 2016600,000 מכשירים נפרצו רק כי נשארה סיסמת ברירת מחדל admin/admin
ספרו את סיפור Mirai – DDoS ענק שהפיל את Twitter/Netflix, בלי פגיעות מתוחכמת. רק סיסמאות ברירת מחדל.

סיסמאות – secret מנצח password

R1(config)# enable secret Str0ng    ! מגובב MD5
R1(config)# enable password weak    ! גלוי – לא!
R1(config)# service password-encryption
R1(config)# username admin secret P@ss
  • password = טקסט גלוי / type 7 (נשבר בשנייה)
  • secret = גיבוב חד-כיווני – לא ניתן לשחזר ✓
הדגישו: type 7 (service password-encryption) מגן רק מהצצה מעבר לכתף. secret הוא האמיתי.

שאלה

מה ההבדל בין login ל-login local?

login = רק סיסמת הקו (כולם אותה סיסמה, בלי שם). login local = שם משתמש + סיסמה מול מסד מקומי. SSH דורש login local!
זה מפתח להבנת SSH בשקף הבא, ונשאל בבגרות (שאלה 2א – התשובה עם login local).

הגדרת SSH – 5 שלבים

R1(config)# hostname R1
R1(config)# ip domain-name school.local
R1(config)# crypto key generate rsa modulus 2048
R1(config)# username admin privilege 15 secret P@ss
R1(config)# ip ssh version 2
R1(config)# line vty 0 4
R1(config-line)# login local
R1(config-line)# transport input ssh
חובה לפני crypto keyhostname + ip domain-name (אחרת: "Please define a domain-name")
הריצו את זה בעצמכם קודם. הטעות #1: שוכחים domain-name. הראו Telnet נכשל אחרי transport input ssh.

Telnet מול SSH

Telnet (23)הכול בטקסט גלוי – שם וסיסמה נראים ב-Wireshark
SSH (22)הכול מוצפן + אימות השרת. גרסה 2 בלבד

מפתחות ה-RSA שיצרנו = הצפנת ה-SSH

הדגמה מנצחת: לכדו Telnet ב-Wireshark, הראו את הסיסמה. זו הצצה לפרק 7 (RSA א-סימטרי).

NTP ו-SNMP

  • NTP (123) – זמן מדויק. בלי זה – לוגים חסרי ערך, תעודות נכשלות
  • SNMP (161) – ניטור ציוד. גרסה 3 בלבד (אימות + הצפנה)
R1(config)# ntp server 10.0.0.5
R1(config)# snmp-server group ADMINS v3 priv
SNMPv1/v2ccommunity string בטקסט גלוי ("public") – חלש. תמיד v3
קשרו NTP ללוגים: אירוע בנתב ב-3 ובחומת אש ב-5 – בלי זמן מסונכרן אי אפשר לשחזר.

AutoSecure וכיבוי שירותים

R1# auto secure       ! הקשחה בפקודה אחת
R1(config)# no ip http server
R1(config)# no cdp run
R1(config)# no ip source-route
זהירותAutoSecure "עיוור" – בדקו מה שינה עם show auto secure config
AutoSecure = המקבילה ל-One-step Lockdown של SDM. נוח אך צריך בדיקה.
